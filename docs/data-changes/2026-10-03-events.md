# Event calendar — single source of truth (2026-10-03)

Before this change two event records existed per city and drifted apart: each month's
`evtTier` + `events` string (which drive the Events score) and the structured list
`city.events` (data/city-content.json) that the city sheet shows as the event calendar.
`scripts/reconcile_events.py` found **16 month conflicts** (the scored month names an event
the list shows in another month) and **41 visible "major" entries** in months scored below tier 3.

## What changed

1. The structured list is now the only place events are edited. `python3
   scripts/reconcile_events.py --derive` sets each month's `evtTier` to the highest tier
   among `city.events` entries covering that month (0 if none) and its `events` string to
   those entries' names (highest tier first, joined with " · ").
2. **Invariant:** `scripts/sanity_check.py` now calls `reconcile_events.check_derived` and
   fails if any month disagrees with the list (`python3 scripts/reconcile_events.py
   --check-derived` runs the same check on its own). Order after editing events:
   `build_city_content.py --only events` → `reconcile_events.py --derive` →
   `rebake_scores.py --write` → `sanity_check.py`.
3. After the derive: 322 city-months changed tier (184 up, 138 down); 437 months changed
   tier and/or label. The reconcile report now shows 0 conflicts and 0 under-scored majors.
4. No blurb was written or invented. One entry was added without a blurb (Granada, Día de la
   Cruz), marked `"from": "event-review-2026-10"`.

## Tier review of the 41 visible majors (and a few others)

The 41 rows were 31 distinct tier-3 entries. Rule applied: tier 3 only for a genuinely major,
travel-worthy festival for that city (worth planning a stay around); a national holiday,
local city day or religious feast without a draw for visitors is tier 2. **8 of the 31 were
lowered to tier 2**; the other 23 kept tier 3 (now scored as such):

## Notes and judgment calls

- Tier-1 entries in the structured list (e.g. Buenos Aires' Sunday Feria de Mataderos,
  Hoi An's monthly full-moon lantern nights) now score their months; the old calendar had
  ignored many of them while scoring season descriptions ("Beach high season") at tier 1.
- The tier rule is editorial and still hand-set; it is now applied in one place.
